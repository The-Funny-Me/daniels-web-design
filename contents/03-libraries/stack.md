# 03 · Stack and libraries

The approved stack. Agents do not add dependencies, fonts or icon sets that are not listed here. If something is missing, stop and ask.

## Core

| Concern | Choice | Notes |
|---|---|---|
| Framework | **Next.js (App Router)** | Server Components by default; `"use client"` only where state, effects or animation need it |
| Language | **TypeScript**, `strict: true` | No `any`; props typed with `interface`; export prop types |
| Styling | **Tailwind CSS v4** | Config lives in CSS (`@theme`), not `tailwind.config.js` |
| Primitives | **shadcn-style on Radix** | Hand-written components in `components/ui/` following the shadcn pattern (`@radix-ui/react-dialog`, `@radix-ui/react-slot`, `class-variance-authority`); restyled through tokens |
| Icons | **Phosphor** (`@phosphor-icons/react`) | `weight="thin"` default, `"light"` at ≤16px or for emphasis |
| UI motion | **Motion** (`motion/react`) | Component states, layout, springs, presence, gestures |
| Sequence motion | **anime.js v4** | SVG drawing/morphing (`createDrawable`), scroll choreography, hero timelines, particle bursts |
| Fonts | **Fontsource** (`@fontsource/cormorant-garamond`, `@fontsource/frank-ruhl-libre`, `@fontsource-variable/inter`, `@fontsource/heebo`, `@fontsource/jetbrains-mono`) | Self-hosted offline-safe packages (replaces `next/font/google` so sandbox builds never depend on network font fetches) |
| Class merging | `clsx` + `tailwind-merge` via a `cn()` helper | shadcn standard |
| Variants | `class-variance-authority` | shadcn standard |


Copy the generated files from `01-fundamentals/` into the project (or reference them by path). Never edit them in the project; change `core.json` / `palettes/*.json` and rebuild.

### Tailwind color names

Only semantic names exist; there is no raw palette to reach for.

`bg-canvas · bg-surface · bg-surface-raised · bg-surface-sunken · text-ink · text-ink-2 · text-ink-3 · border-hairline · border-hairline-strong · border-control`
`bg-brand-solid · hover:bg-brand-solid-hover · text-on-brand · text-brand-text · text-brand-ui · bg-brand` (brand = the accent family)
`bg-deep-solid · text-on-deep · text-deep-text` (deep = the secondary family)
`bg-glass · border-glass-edge · bg-scrim · ring-focus`
`text-success|warning|danger|info`, `bg-success-bg`, `border-success-border` (and the same for the others)

`brand` and `deep` are the Tailwind names for the CSS roles `--ds-accent*` and `--ds-secondary*`; shadcn owns the Tailwind keys `accent` and `secondary`, so the system avoids them.

Other mapped names: `font-display`, `font-sans`, `rounded-pill|card|sheet|editorial`, `shadow-sm|md|lg`, `py-section-xs…xl`, `min-h-touch`, `size-touch` (`--ds-space-touch: 44px`), `max-w-app|marketing|reading`, `ease-soft`. Durations, z-index and glass parameters use arbitrary-value syntax with tokens: `duration-(--ds-duration-ui)`, `z-(--ds-z-modal)`, `backdrop-blur-(--ds-glass-blur)`.

## shadcn/ui rules

- Components in `src/components/ui/` are hand-written in the shadcn pattern (not CLI-generated) and styled directly with semantic token roles (`rounded-pill` for buttons and inputs, `rounded-card` for cards, `.glass` for popovers, dialogs and sheets).
- Buttons: pill, `bg-brand-solid text-on-brand` primary, `bg-deep-solid text-on-deep` secondary, `border-control bg-surface-raised` quiet. Press feedback per UI rule U24; `loading` locks button `width` and `height` (`opacity-0` label + centered `<Spinner />` overlay).
- Dialog, Sheet (`Overlay` / `GlassSheet`) and Toast (`Sonner`) use the `.glass` recipe; the Dialog and Sheet backdrop uses `bg-scrim` plus `backdrop-blur-(--ds-scrim-blur)`.
- Keep Radix's accessibility behavior (focus trap, ARIA) plus explicit focus restoration to the triggering element on close. Never replace a Radix primitive with a div.
- Toasts: Sonner configured with `toastOptions={{ unstyled: true }}` so every toast renders our own `.glass` markup (`toaster.tsx`), bottom-`start` positioned; undo toast 8s with a draining hairline (`--drain-origin`).

## Library boundaries

**Motion owns** anything driven by React state: hover/press, presence (enter/exit), layout transitions, shared elements, modal and sheet entrance (`overlay` spring), stagger of lists on mount, gestures, the animated-input placeholder state machine.

**anime.js owns** anything that is a *timeline or a path*: SVG line drawing and morphing, hero sequences, scroll-scrubbed choreography, accent particle systems. It runs inside `useEffect` or `useLayoutEffect` on refs, is created with `createScope` for cleanup, and respects reduced motion.

Never both on the same element and property. If a component needs both, split it into two nested elements, one per library.

Smooth scroll: **Lenis**, allowed only on marketing surfaces (see `04-signature-moves/scroll-and-focus.md`). It is the one additional dependency permitted for that purpose.

## Project structure

```
src/
  app/                  routes, layouts, globals.css
  components/
    ui/                 shadcn components, restyled (owned)
    patterns/           composed pieces: AnimatedInput, GlassSheet, GhostNumeral, AccentBurst, Loader
    sections/           page sections (landing hero, feature rows)
  design/               tokens.css, shadcn-bridge.css, tailwind-theme.css (copied from 01-fundamentals)
  lib/                  cn.ts, motion presets (springs from core.json), direction helpers
  hooks/                useReducedMotion, useDirection, useAdaptiveLoading
```

Motion presets in `lib/motion.ts` are the only place spring and duration numbers appear, copied from `core.json → motion`. Components import `springs.overlay`, never inline numbers.

## Code conventions (for golden-example pattern matching)

- Named exports for components; default export only for Next.js route files.
- Import order: react/next → third-party → `@/components` → `@/lib` → types → styles.
- One component per file, PascalCase filename; props interface named `<Component>Props`.
- Server Components by default. Mark `"use client"` at the smallest leaf that needs it.
- No inline styles except for CSS variable passthrough (`style={{ "--i": index } as React.CSSProperties}`).
- Every animated component accepts and honors `useReducedMotion()`.
- Strings that users see go through a tiny `t()` dictionary with `en` and `he` entries, never inline literals in markup, so RTL demos swap content.
- No `index.ts` barrel files in `components/ui`.
- Accessibility: no `div` buttons; every icon-only button has `aria-label`.

## Not allowed without asking

Other UI kits (MUI, Chakra, Ant, Mantine), other icon sets (Lucide, Heroicons, FontAwesome), other animation libraries (GSAP, react-spring, framer-motion legacy import path), CSS-in-JS runtimes, Tailwind plugins beyond `tailwindcss-animate`/`tw-animate-css` as shipped by shadcn, any font outside the list, UI component generators that emit raw hex colors.
